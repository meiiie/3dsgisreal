# Design Lab

This folder is for frontend, mobile, and brand exploration before ideas become production UI.

Use it for:

- design prompts and design bibles
- generated image concepts
- mobile screen-flow mockups
- logo and brand-kit explorations
- web UI audits and screenshot notes
- selected raster assets before promotion into the app

Do not treat lab outputs as production assets automatically. When an asset becomes part of the app, move or copy the final selected version into the app's public asset tree and update the consuming code deliberately.

## Folders

- `prompts/`: design briefs, prompt specs, critique notes
- `brand/`: logo, identity, color, icon, and brand-kit explorations
- `mobile/`: mobile app screen concepts and flow images
- `web-ui/`: desktop/web app audits, screenshots, and redesign notes
- `assets/`: selected generated raster assets before app promotion

## Recording Rule

For each serious design experiment, record:

- date
- goal
- skill/tool used
- prompt or design brief
- output path
- selected/rejected decision
- next implementation implication
