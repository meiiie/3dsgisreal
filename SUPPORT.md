# Support

3DGS Real is an early local-lab project.

Use GitHub Issues for:

- reproducible bugs
- docs mistakes
- feature proposals tied to the map, 3DGS pipeline, viewer, admin, or user workflows
- local setup problems

Before opening an issue:

1. Check the README and docs.
2. Include your OS, Node.js version, pnpm version, and browser.
3. Include the exact command and output.
4. Remove secrets, private capture media, and private addresses.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
